# Kwa Njenga Circular Economy & Enterprise Hub

One-page project site for the Kwa Njenga Circular Economy & Enterprise Hub, Nairobi.

## Deploy on GitHub Pages

1. Create a new GitHub repository named **`kwa-njenga-circular-economy-hub`** (or another name of your choice — this doesn't have to match exactly).
2. Upload these three items to the **root** of that repository:
   - `index.html`
   - `styles.css`
   - `assets/` folder (contains `founder.jpg`)
3. In the repo, go to **Settings → Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`, choose branch `main` and folder `/ (root)`, then **Save**.
5. Wait 1–2 minutes. Your site will be live at:
   `https://<your-github-username>.github.io/kwa-njenga-circular-economy-hub/`

## Editing later

- All copy lives directly in `index.html` — open it in any text editor and edit the text between tags.
- Colors and fonts are defined once at the top of `styles.css` under `:root`, so changing the accent color, for example, only requires editing the `--rust` value in one place.
- To swap the founder photo, replace `assets/founder.jpg` with a new image of the same filename, or update the `src` path in `index.html`.
